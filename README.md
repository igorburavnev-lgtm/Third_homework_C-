# Домашнее задание: три стратегии для турнира «Делить или красть»

**Автор:** Буравнёв Игорь Евгеньевич

## Что внутри

| Файл | Турнир | Стратегия | Результат (финал, сид 42) |
|---|---|---|---|
| `BuravnyovSelfish.cs`   | 1. Эгоист     | Tit-for-Tat с зеркалированием ставки и наказанием воров | 3 место из 14 (22.6 очка) |
| `BuravnyovSociety.cs`   | 2. Общество   | Максимальная кооперация (bet 100), SKIP-наказание воров, bet 1 против хищника | 2 место из 14 (23.9) |
| `BuravnyovSurvivor.cs`  | 3. Выживание  | Кооперация + оппортунистические кражи с бюджетом (≤2 за 10 ходов) у наивных богатых | **1 место из 14 (28.7)** |

## Идея

- **Эгоист:** наказываем воров, зеркалим ставку честных, но не зацикливаемся на мести.
- **Общество:** максимизируем общий пирог, ставим 100, но SKIP-аем воров, чтобы они не разбогатели.
- **Выживание:** копируем статы и подход топ-бота Кати — честная сделка на 100 + редкие кражи у наивных с бюджетом на 10 ходов.

Все три файла прошли `dotnet run -- check` без замечаний.
